# others

Private files, never committed (see `.gitignore`):

- `address/address.txt`: your postal address, as you'd type it into a form. Add a ready-made
  "line 1 / line 2" split if forms often have two address lines.
- `contacts/phone.txt`: your phone number with the country code (say if it's also on WhatsApp).

Claude reads them only when a form asks for an address or phone number, and never copies them into any other file.
