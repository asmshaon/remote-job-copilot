# Resume guide (optional)

How your tailored resumes should read. The custom-resume skill reads this file for every resume, in
either style. Delete what you don't need, or remove the file to use the defaults. Example values below
are for a made-up person.

## Sources
- Facts come only from `contributions/` and `skills/my-skill-set.md` (name the main file here if you
  have several, e.g. a detailed project inventory PDF).
- Clients: anonymize by domain (e.g. "US fitness marketplace") unless you are allowed to name them.

## Positioning
- Senior backend engineer who can own a product end to end at a startup, or improve an existing system.
- Tone: confident and practical, never needy. Business outcomes over lists of tools.

## Things to keep in the background
- e.g. DevOps is a supporting skill: never in the tagline, at most one bullet per role, placed last.

## Writing
- e.g. British spelling, no em dashes, no marketing words.

## Shape (modern style only)
- Tagline: one line, role-focused for each job.
- Summary: 3 to 4 sentences.
- Skills: 6 categories with 3 to 4 items each.
- Older roles (before 2015) in one "Earlier Experience" paragraph.
